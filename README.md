# PC-Hardware-Notes

记录我装机时以及之后遇见的问题。

## 宿舍环境下的显卡高温排查

### 现象
RTX 5060 Ti 在运行负载3D游戏（如《绝区零》）时，满载温度从家里的 73°C 飙升至 83°C（标红）。

### 排查
1. 机箱侧板紧贴墙壁，且墙壁存在掉粉现象。
2. 机箱底部装有一个风扇，但装反了方向（向下出风），导致显卡无法从底部吸取冷空气。
3. 以及因为装了风扇调试软件（如FanControl），平时普通负载未能察觉积热问题。

### 解决
将机箱拉出，离墙保持 10 厘米以上的距离，避开底部风扇的下压风道。
再次满载测试，温度回落到 77°C。

### 结论
机箱风道受阻会形成严重的热风循环，导致硬件温度异常。在宿舍环境下，物理隔离（远离墙壁）是成本最低、最有效的散热改造方案。
（尤其是新手只注重整机性能而缺少调整）
